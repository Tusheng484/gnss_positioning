# 输入数据准备

本目录放置本地 NovAtel OEM 二进制日志。原始课程日志未随本次仓库整理上传。

示例配置期望 `data/NovatelOEM20211114-01.log`。可以放置同名日志，也可修改 `config/params.yaml` 中的 `io.input_path`。文件名无特殊要求，输入内容必须是支持的 OEM 二进制消息流。

## 必要消息

| 消息 | ID | 用途 |
| --- | --- | --- |
| RANGE | 43 | 伪距、载波相位、多普勒与信噪比 |
| GPSEPHEM | 7 | GPS 广播星历 |
| BDSEPHEMERIS | 1696 | BDS 广播星历 |

缺少对应星历时无法定位。双频 IF 模式需要 GPS L1/L2 或 BDS B1I/B3I 双频观测；单频设置见 [配置说明](../docs/CONFIGURATION.md)。

## 历史课程文件

原作者本地保存了 `Novatel OEM7 Data/01/`、`02/`、`03/` 数据组。课程随附说明区分：

- `.log`：原始二进制日志，可作为本程序输入。
- `.21*`：NovAtel 工具解码产物。
- `.obs`、`.nav`：RTKLIB 解码产物。
- `*-GPS&BDS-Double.obs`：GPS/BDS 双频观测结果，供课程解码对比。

本程序不直接读取 RINEX 产物，也不将 `.pos` 作为定位输入。已有课程参考解 `参考数据/NovatelOEM20211114-01.pos` 保留在 Git 记录中，供历史分析脚本使用；它不能替代原始日志。

请从课程原提供方或自行采集的数据中准备合法可用的日志。`data/` 内除本说明外的文件均被忽略，其他本地数据目录和运行输出同样不随提交上传。
